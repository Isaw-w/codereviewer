# Data map

This file maps the main release artifacts to the current paper findings, main tables, figures, and appendix support.

## Finding 1: rubric-list capture

- `data/paper_release/finding1/rubric_as_response_capture/summary_all_models_nointro_underlying_eval_point_capture.json`
  - Main 100-case Finding 1 summary used for `tab:rubric_capture`.
  - Contains the three frontier models and four smaller-model baselines, with rubric-list capture scores, open-ended-response MoReBench scores on the same 100 cases, and the gap.
- `data/paper_release/finding1/rubric_as_response_capture/summary_three_models_nointro_underlying_eval_point_capture.json`
  - Original three-frontier-model summary retained for provenance.
- `data/paper_release/finding1/rubric_as_response_capture/{gemini25_pro,gpt54,opus46}/`
  - Per-model inputs, judge outputs, and capture summaries for the frontier-model rubric-as-response check.
  - These files are regenerated by `code/bin/04b_run_finding1_rubric_capture`.
- `data/paper_release/finding1/rubric_as_response_capture/small_model_baselines/`
  - Per-model inputs, judge outputs, and capture summaries for LLaMA 3.1 8B, LLaMA 3.2 3B, Mistral 7B v0.1, and Qwen 2.5 7B.
- `data/paper_release/finding1/open_ended_response_eval/small_model_baselines/`
  - Human-rubric MoReBench judgement outputs for the smaller-model open-ended responses on the same 100 cases.
