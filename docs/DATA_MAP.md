# Data map

This file maps the main release artifacts to the findings, table numbers, figure numbers, and appendix support they feed.

## Finding 1

- `data/paper_release/finding1/criterion_pairs/finding1_confirmed_pairs.json`
  - Main matched-pair artifact used for the fulfillment-gap analysis.
  - Used for the headline `5,181` matched pairs and the cosine-binned gap table.
- `data/paper_release/finding1/criterion_pairs/all_bidir_pairs_data.json`
  - Alias copy of the same staged pair artifact used in older internal analyses and appendix breakdowns.
- `data/paper_release/finding1/rubric_as_response_capture/summary_three_models_nointro_underlying_eval_point_capture.json`
  - 100-case rubric-as-response capture summary for Gemini 2.5 Pro, GPT-5.4, and Opus 4.6.
  - Used for the claim that model-written rubrics capture over 80% of the underlying evaluative content of expert-authored human criteria on this slice.
- `data/paper_release/finding1/rubric_as_response_capture/{gemini25_pro,gpt54,opus46}/`
  - Per-model inputs, judge outputs, and capture summaries for the same rubric-as-response check.
  - These files are regenerated by `code/bin/04b_run_finding1_rubric_capture`.
